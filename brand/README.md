# Brand assets

The `[ ]` mark. Amber `#ffb000` on near-black `#0b0a08`.

- `amick-labs-mark` — square tile. Use this for avatars; most uploaders apply their own circle or rounded crop.
- `amick-labs-mark-rounded` — same as the site favicon, 12/64 corner radius.
- `amick-labs-mark-circle-512` — pre-cropped circle for places that don't crop.
- `amick-labs-mark-amber` — inverted: amber tile, dark brackets. For when the dark tile disappears on a dark UI.
- `amick-labs-mark-transparent` — brackets only, no background.
- `favicon.ico` — multi-size (16–256) from the rounded mark.

PNGs at 64 / 128 / 256 / 512 / 1024. SVGs are the source; re-render with a browser, not ImageMagick (its SVG renderer drops the stroke).
